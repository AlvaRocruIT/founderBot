<b><big> ✒️ founderBot</b></big>

Bienvenido al chat interactivo para postulantes a fondos concursables públicos y privados.
Este proyecto apoya tus postulaciones: en lugar de bancarte documentación eterna, ahora puedes preguntar directamente lo que necesitas saber.

<b>💡 ¿Qué es esto?</b>

founderBot es un chatbot diseñado para representar varias convocatorias en formato conversacional.
Permite que emprendedores como tú interactúen con los fondos concursables, conozcan sus requisitos y hagan preguntas, mientras vas preparando:

✅ el nivel de profundización, <br>
✅ dudas recurrentes, <br>
✅ lo que busca la organización, <br>
✅ y una visión estratégica de cómo abordar desafío. <br>

En vez de solo leer un PDF, puedes interactuar adaptando la información a tu prototipo.

<b>🎯 Propósito</b>

Este proyecto nace de la convicción de que postular es generar tu propia información, no la que te entregan.

Aquí combinamos:

🌱 Narrativa emprendedora (fondos concursables que hablan en tu propio lenguaje y propósito). <br>
🌱 Tecnología conversacional (para experiencias más humanas y accesibles). <br>
🌱 Automatización (para integrar este paso en flujos de postulación modernos). <br>
🌱 El resultado: procesos de difusión más empáticos, eficientes y significativos. <br>

<b>👨🏻‍💻 Tecnologías utilizadas</b>

FastAPI para orquestar el flujo conversacional.
OpenAI; DeepSeek para generar respuestas inteligentes y dinámicas.
GitHub Pages para alojar el frontend (HTML + CSS + JavaScript).
PostgreSQL + Supabase para alojar base de datos del dashboard.
OpenAI para mejorar la toma de decisiones en el desarrollo.
